## 关键设计决策

### 高精度快门定时器
使用 RP2040 硬件定时器 (`hardware/timer.h`) 实现微秒级精度：
- 目标精度：±50μs
- Python 原实现：±5ms (machine.Timer)
- 改进倍数：100 倍

### 代码组织
- 当前：所有逻辑在 `SX70Mk2.c` 中
- 目标：按功能模块拆分到 `camera/` `ui/` 目录
