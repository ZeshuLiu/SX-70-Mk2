# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 项目概述

SX-70 Mk2 相机控制器 - 基于 Raspberry Pi Pico 的胶片相机控制系统，从 MicroPython 重构为 C 语言以提升快门定时器精度（目标：±50μs）。

## 构建命令

```bash
# 进入构建目录
cd build

# 配置项目（首次）
cmake ..

# 编译
cmake --build .

# 生成 UF2 文件：build/SX70Mk2.uf2
```

## 已完成功能

### 驱动层
- **PCF8575**: I2C GPIO 扩展 (16 位输入)
- **SSD1306**: 128x32 OLED 显示
- **TSL2561**: 测光传感器 (自动增益切换)
- **LED**: 状态指示灯

### 核心控制
- **快门控制**: PWM 20kHz + 硬件定时器 (精度 0.1ms)
- **测光系统**: 7 次采样平均，(lux-0.4)*0.9 校准
- **快门速度表**: 22 档 (1s ~ 1/2000C)
- **对焦逻辑**: S1F 半按对焦，S1F_FBW 反馈
- **闪光灯检测**: S2 引脚检测，自动切换闪光模式

### 用户界面
- **3D 按键**: 上/下/按下，支持长按识别
- **OLED 显示**: 模式/ISO/快门速度/LUX/闪光状态
- **菜单系统**: AUTO/M/B/T 模式切换

## 硬件架构

### I2C 设备
- **I2C0** (GPIO20/21): TSL2561 测光传感器
- **I2C1** (GPIO18/19): PCF8575 IO 扩展 + SSD1306 OLED

### 关键引脚
- **快门 PWM**: GPIO9 (20kHz, 1000 步分辨率)
- **光圈 PWM**: GPIO17 (70kHz, 待实现)
- **马达**: GPIO5
- **按键输入**: 
  - S1F (半按对焦): GPIO2
  - S1T (全按拍摄): GPIO1
  - S2 (闪光检测): GPIO14, PULL_UP
  - S3 (反光板检测): GPIO7, PULL_UP
  - S5 (胶片检测): GPIO6, PULL_UP
- **输出控制**:
  - MOTOR (马达): GPIO5
  - FF (闪光灯触发): GPIO11
  - S1F_FBW (对焦反馈): GPIO22

### PCF8575 连接
- I2C 地址：0x20
- P2: Button3D 按键 (下/上/按下)

## PWM 配置

### 快门 PWM (GPIO9)
```c
wrap = 999 (1000 步)
div = 4.0
频率 = 125MHz / (4 × 1000) = 31.25 kHz
```

## 重要注意事项

1. **USB 串口**: Pico CDC 串口需要在电脑端启用硬件流控 (RTS/CTS) 才能正常输出
2. **Bootloader**: 启动时检测 Button3D，按下则进入 UF2 Bootloader
3. **参考代码**: 原 MicroPython 实现在 `E:\Develop\SX-70-Mk2\Code\MainControllerCode`
4. **定时器精度**: RP2040 硬件定时器，1μs 分辨率，当前使用 0.1ms 单位 (×100 转换)
5. **闪光灯同步**: 有闪光灯时，快门速度 ≥ 1/30s (ev11)
